
# Advanced Java Programming

**Valencia College | Spring 2026**  
**Course:** COP 2805C - Advanced Java Programming

## About This Repository

This repository contains projects I worked on during my Advanced Java Programming course at Valencia College.

Throughout the semester, I learned more about Java, practiced different programming concepts, and worked on projects that helped me improve my coding and problem-solving skills.

## My Projects

### 1. Java Collections

I practiced using Stack, Queue, ArrayList, and HashMap to organize and manage data in Java.

### 2. File Input and Output

I created a simple program that writes names to a text file and reads them back.

### 3. Java Generics

I created a program that uses a generic class to store different types of food in a bucket.

### 4. Polymorphism and Nested Classes

I worked with different car classes to practice inheritance, polymorphism, method overriding, and nested classes.

### 5. Multithreading - Tortoise and Hare Race

This was one of my favorite projects!

I created a race between a tortoise and a hare using Java threads.

Both run 10 laps, and the first one to finish wins.

In the video, I show the tortoise winning first. Then I change the code so the hare wins.

[🎥 Watch My Tortoise and Hare Race](https://youtu.be/WdYDvoX_1Ec)

### 6. Spring Boot - Harry Potter Character Creator

I created a web application where users can make their own Harry Potter character by choosing things like their Hogwarts house, wand, and favorite spell.

I also worked on another version that saves the character information in an H2 database.

### 7. Spring Boot - Student Lab Sign-In

I created a student sign-in form using Spring Boot.

Students can enter their name, Valencia College email, and course.

The program checks the information before saving it to an H2 database.

In the video, I show the form, the validation messages, my code, and the saved information in the database.

[🎥 Watch My Student Lab Sign-In Project](https://youtu.be/NDAfQy1yoDw)
